Your task is to analyze a search query and determine what seniority level the user is looking for.

junior < mid < senior < staff < principal < manager < director < vice-president < c-suite < partner < owner

## ⚠️ CRITICAL DISAMBIGUATION RULES

### Job titles that are NOT seniority requests:
- **"Account Manager", "Product Manager", "Program Manager", "Project Manager", "Customer Success Manager"** → ["junior", "mid", "senior", "staff"] unless explicitly leveled. They manage accounts, products, programs, projects, or customer relationships, not necessarily people. "Senior Account Manager" → ["senior"]; "Head of Account Management" → ["director", "vice-president"].
- **"Account Executive"** → ["mid", "senior"]. "Executive" is part of the sales title, NOT c-suite.
- **"Executive Assistant"** → ["junior", "mid"]. Admin support, NOT c-suite.
- **"Executive Producer"** → ["senior", "director"]. Creative role, NOT c-suite.
- **"Managing Director" at a bank** → ["director", "vice-president"].
- **"Principal Engineer"** → ["principal"]. Senior IC track.
- **"Staff Engineer"** → ["staff"]. Senior IC track.
- **"Technical Lead"** → ["senior"]. Usually IC despite "lead" title.

### True seniority indicators:
- **"executives"** (standalone) → ["c-suite", "vice-president"]
- **"leadership"** / **"leaders"** → ALL 7 leader bands: ["c-suite", "vice-president", "director", "owner", "partner", "manager", "principal"]
- **"C-level"** / **"C-suite"** → ["c-suite"]
- **"VP"** / **"Vice President"** → ["vice-president"]
- **"Director"** → ["director"]
- **"Manager"** / **"managers"** → ["manager"]
- **"ICs"** / **"individual contributors"** → ALL IC bands: ["staff", "senior", "mid", "junior"] (NO principal — principal is in the leader group)
- **"senior+"** → ["senior", "staff", "principal"]

### Range modifiers:
- **"senior or above"** / **"senior+"** → ["senior", "staff", "principal"] (IC track)
- **"director and above"** → ["director", "vice-president", "c-suite", "partner", "owner"]
- **"mid-level"** → ["mid"]
- **"entry-level"** → ["junior"]
- **"junior to mid"** → ["junior", "mid"]
- **"junior X"** → ["junior"] only

### Conventional-title disambiguation:
A title can contain a level-like word without requesting that literal band. Do not map one word from
the title independently; classify the complete candidate role using the default below.
Words such as Analyst, Associate, Assistant, Coordinator, Member of Technical Staff, MTS, Principal,
or Executive can be part of a conventional occupation. They are not independent level
modifiers when they occur only inside that title.
Only the candidate population can request a band. Ignore role and level words naming someone the
candidate supports, reports to, sells to, recruits for, advises, or builds for; those describe the
relationship's object, not the candidate's seniority.

---

## DEFAULT IC BEHAVIOR

When a query names an IC candidate role but does not request another level or range, return the
general IC bands: ["junior", "mid", "senior", "staff"]. Explicit level words override this default.
"Lead" maps to ["senior"]. "Head of" maps to ["director", "vice-president"].
Leadership, founder, partner, and other non-IC roles use their explicit mappings above. "Any
seniority" means return an empty list.

Common role-specific ranges override the general default:
- recruiters → ["junior", "mid", "senior"]
- sales development representatives / SDRs / BDRs → ["junior"]
- founding engineers → ["senior", "staff", "principal"]
- chief of staff → ["director", "c-suite"]
- investment banking analysts → ["junior", "mid"]
