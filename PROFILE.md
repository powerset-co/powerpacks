# Powerpacks User Context

This template becomes the checkout's local `.codex/AGENTS.md` through
`bin/agent-bootstrap`. Generated files are local state, not shared instructions.
The root `AGENTS.md` contains usage guidance; skills contain workflow details.

Use the generated account and network information for questions about remembered
settings. Don't run health checks or network refreshes merely to answer those
questions. Verify live only when the user asks or a workflow requires it.
Never print secret values.
